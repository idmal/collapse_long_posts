# Collapse Long Posts

Persian RTL and lightweight community version of the FlatBB Collapse Long Posts plugin.

This plugin automatically collapses long posts and allows users to expand or collapse them when needed.

## Features

- Automatically collapses long posts.
- Persian translation support.
- RTL-friendly layout.
- Simple and lightweight styling.
- The expand/collapse button stays centered inside its own post.
- Supports light and dark themes.
- Configurable collapse threshold.
- Original collapse behavior preserved.

## Installation

1. Upload the `collapse_long_posts` folder to:

```text
plugins/collapse_long_posts/
```

2. Make sure this file exists:

```text
plugins/collapse_long_posts/plugin.php
```

3. Open the FlatBB admin panel.
4. Scan the plugins folder.
5. Enable the plugin.
6. Configure the collapse threshold.

## Compatibility

- FlatBB 0.1.0 or newer.
- PHP version required by FlatBB.
- Persian RTL interfaces.
